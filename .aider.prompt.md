# open-agent-engine - Aider Instructions

> Cross-platform multi-agent scaffolding, skill package manager, and transpiler engine

## Shell Commands
- Test Suite: `pnpm test`
- Build: `pnpm build`
- Typecheck: `pnpm typecheck`

## Operational Guardrails
- ALWAYS execute `pnpm test` after modifying code.
- Never introduce breaking changes without updating tests.
